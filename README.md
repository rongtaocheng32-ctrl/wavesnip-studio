# 声剪 WaveSnip

声剪 WaveSnip 是一个零依赖的静态 Web 音频裁切工具。它使用 Web Audio API 在浏览器中解码音频、绘制波形、试听选区，并在本地生成 16-bit PCM WAV。音频文件不会上传到服务器。

在线使用：<https://rongtaocheng32-ctrl.github.io/wavesnip-studio/>

## 问题

很多在线音频剪辑器要求上传文件、登录账号或等待云端转码。对于会议录音、采访、未发布的节目等素材，这会带来隐私和等待成本。

声剪把这条链路放回本地：页面载入后，解码、效果处理与 WAV 编码都由当前浏览器完成。

## 主要功能

- 点击选择或拖放本地音频文件。
- 使用 Web Audio API 解码音频并绘制波形。
- 通过波形拖动、双滑块或开始/结束秒数设置裁切选区。
- 试听选区并随时停止。
- 设置 0–100% 音量、淡入时长和淡出时长。
- 可选峰值归一化，将选区峰值调整到 0.98（约 -0.18 dBFS）。
- 在浏览器中编码并下载 16-bit PCM WAV，保留解码后的采样率和声道数。
- 使用 `localStorage` 保存最近 20 条导出参数，可一键清空。记录不包含音频数据。
- 响应式界面、键盘焦点样式、状态和错误提示。
- 移除文件或关闭页面时停止播放并释放已创建的浏览器资源。

## 安装

本项目没有构建步骤和第三方依赖。

```bash
git clone https://github.com/rongtaocheng32-ctrl/wavesnip-studio.git
cd wavesnip-studio
python3 -m http.server 4173
```

在浏览器打开 <http://localhost:4173>。

也可以直接双击 `index.html`，但某些浏览器对 `file://` 页面的存储或音频权限有额外限制，因此推荐使用本地 HTTP 服务器。

## 使用

1. 将音频拖入上传区，或点击「选择文件」。
2. 等待浏览器完成解码和波形生成。
3. 在波形上拖动，或使用双滑块/秒数输入框设置选区。
4. 点击「试听选区」确认边界。
5. 设置音量、淡入、淡出；需要时打开「峰值归一化」。
6. 点击「导出选区 WAV」。编码完成后浏览器会下载文件。
7. 导出参数会出现在页面下方。「清空记录」只删除本地参数记录，不会删除已下载的 WAV。

## 输入输出示例

### 示例 1：会议录音抽取

- 输入：`weekly-meeting.m4a`，48 kHz，双声道，18:42.500。
- 选区：`00:35.200` 至 `02:08.900`。
- 处理：音量 90%，淡入 0.3 秒，淡出 0.8 秒，开启峰值归一化。
- 输出：`weekly-meeting-wavesnip-00m35s200-02m08s900.wav`，16-bit PCM，48 kHz，双声道。

### 示例 2：短音效裁切

- 输入：`field-recording.wav`，44.1 kHz，单声道。
- 选区：`05.000` 至 `07.250`。
- 处理：音量 100%，不归一化，淡入/淡出各 0.1 秒。
- 输出：`field-recording-wavesnip-00m05s000-00m07s250.wav`，16-bit PCM，44.1 kHz，单声道。

## 浏览器兼容与限制

- 推荐使用较新版本的 Chrome、Edge、Firefox 或 Safari。必须支持 Web Audio API、Canvas、Blob 和 `localStorage`。
- 可打开的格式与编码由浏览器决定，同一文件在不同浏览器中可能有不同结果。WAV 和 MP3 通常最稳定；M4A/AAC/OGG/FLAC 的支持取决于系统和浏览器。
- 工具会把完整音频解码到内存，导出时还会分配 WAV 缓冲区。长时音频或多声道高采样率文件可能超出移动设备或浏览器的可用内存。
- 输出使用经典 RIFF/WAV PCM 容器，单个文件的数据区不能超过约 4 GB。
- 输出为 16-bit 有符号 PCM，不保留原始文件的有损编码、容器元数据、封面、章节或标记。
- 峰值归一化基于所有解码声道的样本峰值，不是 LUFS 响度标准化。归一化后会再应用音量与淡入/淡出。
- 导出记录是浏览器本地数据；无痕模式、禁用存储、清理站点数据或更换浏览器后，记录可能丢失。
- 本项目不包含多轨时间线、无损流拷贝、噪声消除、变速、格式选择或云端备份。
